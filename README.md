# 🪨📄✂️ Rock Paper Scissors Game

A web-based implementation of the classic Rock, Paper, Scissors game built with Python and a responsive HTML/CSS frontend.

## ✨ Features
* **Interactive Gameplay:** Play against the computer with instant round results (Win, Lose, or Draw).
* **Score Tracking:** Keeps track of player and computer scores across rounds.
* **Clean & Responsive UI:** Styled with custom CSS for a smooth experience across devices.

## 🛠️ Tech Stack
* **Backend:** Python (`app.py`)
* **Frontend:** HTML5 (`index.html`), CSS3 (`style.css`)
